⚡ MOT-CycleControl

Web Flasher - Install Firmware via Browser

⚠️ Safety Warning

This is a MOT spot welder controller. Microwave Oven Transformers (MOT) produce extremely high current (>1000A) at dangerous voltages. Improper use can cause fires, explosions, or fatal electric shock. Only qualified personnel should work with mains voltage equipment. Use appropriate RCD, fuses, and enclosures.

📋 Requirements

  • Chrome, Edge, or Opera browser (Web Serial API support)
  • USB cable (data cable, not charge-only)
  • ESP32 DevKit board
  • Driver installed (CP2102/CH340 depending on your board)

🔥 Flash Firmware

Click the button below to install MOT-CycleControl firmware to your ESP32.

📖 Installation Steps

1
Connect ESP32 Plug your ESP32 DevKit into your computer via USB cable. Ensure it's a data cable (not charge-only).
2
Click "Install Firmware" Click the orange button above. A browser popup will appear asking to select a serial port.
3
Select COM Port Choose your ESP32's COM port (usually labeled "CP2102" or "CH340"). Click "Connect".
4
Wait for Flash The process takes 30-60 seconds. Do NOT disconnect during flashing. Progress bar will show status.
5
Connect to Wi-Fi After flashing, ESP32 will reboot. Connect to Wi-Fi AP: MOT-CycleControl / motspotweld
6
Access Web UI Open browser and go to: http://192.168.4.1

✨ Features

  • Cycle-based timing (50 Hz AC → 1 cycle = 20 ms)
  • HELD HIGH signal for SSR Zero-Cross (fixes "no current" issue)
  • Single & Double Pulse modes (P1 + GAP + P2)
  • Material presets (Pure Nickel, Ni-Plated, Copper)
  • Physical UI (OLED + Rotary Encoder)
  • Web UI (SoftAP + REST API)
  • OTA firmware updates
  • Re-entrancy & cooldown protection

🔌 Pin Configuration

  • SSR Control: GPIO26 (via 5V rail)
  • Encoder CLK: GPIO32
  • Encoder DT: GPIO33
  • Encoder SW: GPIO25
  • OLED SDA: GPIO21
  • OLED SCL: GPIO22 (I2C addr 0x3C)
  • Trigger Button: GPIO27 (optional)

⚡ SSR Wiring Notes

CRITICAL: SSR input is driven directly from ESP32 board's 5V rail (NOT 3.3V). Verify your SSR input current is <12mA. GPIO26 controls the 5V path via external board routing. SSR Zero-Cross type required (NOT Random-Fire/Phase-Angle). Test with 12V bulb before connecting MOT to mains!
